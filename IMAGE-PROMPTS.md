# 🖼️ AI Image Prompts for Renu's Wedding Site

These prompts are written for tools that let you **upload a photo + a text prompt**
(e.g. ChatGPT / DALL·E, Google Gemini / Nano Banana, Midjourney with an image
reference, Adobe Firefly, Flux, Krea, etc.).

### ⭐ Golden rules so the couple still looks like themselves
- Always **upload the real photo** and add a line like:
  *"Keep the faces, skin tone, glasses, and likeness exactly the same — only improve lighting, clarity, and background."*
- Ask for **photo-realistic** results, not illustration, unless you want the artistic version.
- Generate at high resolution (at least **2000px** on the long edge) so it stays sharp.
- If a face looks "off," regenerate — don't settle; likeness matters most.

## 📥 After you generate
1. Download the enhanced image.
2. Rename it to match the file it replaces (e.g. `reenu4.jpeg`).
3. Drop it into the **`images/`** folder, overwriting the old one.
4. Re-upload to GitHub (or commit) — the website updates automatically.

> Tip: keep the **same filename and roughly the same shape** (landscape stays landscape,
> portrait stays portrait) so the layout stays perfect.
