## 🚀 How to publish on GitHub Pages (free, ~5 minutes)

You don't need to install anything.

### 1. Create a GitHub account
Go to [github.com](https://github.com) and sign up (free) if you don't have one.

### 2. Create a new repository
- Click the **+** (top-right) → **New repository**.
- Repository name: `renu-wedding` (or anything you like).
- Set it to **Public**.
- Click **Create repository**.

### 3. Upload these files
- On the new repo page, click **uploading an existing file**.
- Drag in **everything** from this folder:
  `index.html`, `styles.css`, `script.js`, and the whole **`images`** folder.
- Click **Commit changes**.

> Tip: to keep the `images` folder, drag the folder itself (not just the files) into the upload box.

### 4. Turn on GitHub Pages
- In the repo, go to **Settings** → **Pages** (left sidebar).
- Under **Branch**, choose **main** and **/ (root)**, then click **Save**.
- Wait 1–2 minutes and refresh. GitHub will show a link like:

  `https://YOUR-USERNAME.github.io/renu-wedding/`

### 5. Share that link! 🎉
Send it on WhatsApp — it will even show the couple's photo as a preview.

## 💡 Want a prettier link?
A custom domain like `renuwedding.com` can be bought (~₹800/year) and connected in
**Settings → Pages → Custom domain**. Totally optional — the free `github.io` link works perfectly.
